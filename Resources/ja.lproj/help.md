# はじめに

設定、次にソースを開きます。Xtream のログイン、M3U の URL、M3U ファイル、または Stalker ポータル（アドレスと MAC）を追加します。Xtream と Stalker は番組表を一緒に取り込みます。番組表を指定した M3U も同様です。指定がなければ番組表の URL を追加してください。サーバー欄に Xtream のパネルリンクを丸ごと貼り付けると、ログインが自動で入ります。

# メイン画面

検索は一番上です。セクション内のすべてのグループを検索し、完全に一致する名前が先に出ます。隣の音声で話して入力できます。クリアで消えます。

その下にライブTV、映画、シリーズ。次に放送中、番組表を検索、録画、その他。

最初にカテゴリが開きます。カテゴリを選ぶと、そのチャンネルが表示されます。すべて表示する場合は「すべて」を選びます。iPhoneとiPadにはブラウズ、番組表、録画、設定のタブがあります。iPad、Apple TV、Vision Proではカテゴリは左側です。両方のリストに見出しがあります。カテゴリを選ぶとチャンネルに移動します。

キーボードの数字キーでそのチャンネル番号に移動します。

# その他

前のチャンネル、最近見たもの、チャンネル番号へ移動、ソースを更新、番組表を更新、アカウント、設定、アップデートを確認、ヘルプ。

# 項目

実行すると再生します。シリーズはエピソードを開きます。

アクションローター: 他のアプリで再生、お気に入り、詳細、番組表、録画または録画停止、ダウンロード。VoiceOver なしでは長押し。Apple TV では選択ボタンを長押し。

# 番組表

放送中は、いま放送しているものをすべて表示します。チャンネルの番組表は、見逃しの印が付いた過去の番組を再生し、これからの番組を予約します。番組表を検索は、これからの番組を探します。

# プレーヤー

iPhoneとiPadでは「最小化」でタブの上のミニプレーヤーに再生を続けられます。タイトルや映像をタップすると開きます。一時停止と再生停止は別の操作です。開いたプレーヤーには音声、字幕、録画、再生先、AirPlay、全画面があります。キーは音声がA、字幕がS、全画面がF、最小化がEscapeです。VoiceOverでは2本指のダブルタップで再生と一時停止を切り替えます。

全画面ではボタンが隠れます。タップ、Escape、またはリモコンの戻るボタンで戻ります。

チャンネルに音声解説があれば選ばれます。選んだトラックはチャンネルごとに記憶されます。

ストリームの字幕は映像に表示されます。字幕ファイルは映像の下に表示され、SRT と WebVTT は読み上げもされます (設定の字幕を読み上げるがオフの場合を除く)。

番組が変わると、プレーヤーが放送中の番組を伝えます。設定の読み上げで、プレーヤーがどれだけ話すかを選べます。

途切れたライブ配信は自動で再接続します。画面をロックしても音声は流れ続けます。

iPhoneとiPadでは、AirPlayはAppleのプレーヤーで対応映像を送信します。他のIPTV映像は、このデバイスでH.264とAACに変換します。別のサーバーは不要です。再生先はChromecastにも同じ変換を使います。変換中はアプリを開いたまま、受信機と同じWi-Fiに接続してください。電池を消費し、保護された配信や処理能力不足では失敗する場合があります。音声専用の受信機では音声のみ再生します。Apple TVとVision Proはデバイス上の再生に対応し、映像送信は保証しません。 「再生先」を選び、デバイスを選択してください。AirPlayとCastのデバイスにはラベルが付いています。必要な場合、映像変換は自動で始まります。 映像を送信する前に音声と字幕を選んでください。

# 録画

ファイル App に保存されます: このiPhone内 (または iPad)、Accessible IPTV、Recordings。録画中のものが先頭に並び、実行すると停止します。

予約録画は終了後 2 分まで続きます。前後の分数は設定で変えられます。録画中と、6 時間以内に録画が始まるとき、アプリはバックグラウンドで動き続けます。アプリが閉じられていた場合は、開始時刻に通知でアプリを開くよう求めます。

途中で終わった見逃しのダウンロードは、もう一度取得します。

# 設定

設定をエクスポートは、ソース、ログイン、お気に入り、オプションをファイルに保存します。設定をインポートは、この機器、別の機器、または Android アプリのファイルを読み込みます。言語は設定 App のこのアプリのページを開きます。

# アップデート

アプリは 1 日 1 回新しいバージョンを確認します。その他、アップデートを確認ですぐに確認します。インストールで AltStore が開き、インストールします。

# CarPlay

CarPlay にはお気に入りと最近見たライブチャンネルが並び、音声を再生します。Apple の CarPlay オーディオ権限で署名されたビルドが必要です。

# Apple TV

Apple TV には音声検索、M3U ファイル、設定ファイルがありません。システムがアプリの保存領域を消すことがあり、その場合プレイリストと番組表は再ダウンロードされ、録画は失われることがあります。

# Siriとショートカット

iPhoneではSiriとショートカットで名前や番号によるチャンネル選択、現在と次の番組の読み上げ、番組表の検索と表示、再生の一時停止・再開・停止ができます。アプリ名を含めて話してください。Siriが検索語を尋ねます。プレイリストを追加してアプリを開き、番組表を取り込んでください。回答は取り込んだ番組表を使います。操作はApple Intelligenceなしでも使えます。画面上のチャンネル情報の連携にはiOS 18.2以降とシステムの対応が必要です。

Accessible IPTVでSky Mixを再生、Accessible IPTVでSky Mixに切り替え、またはAccessible IPTVでSky Mixを見る、と話してください。チャンネルをお気に入りに追加するか一度再生すると、Siriに名前が登録されます。配信元の接頭辞や画質は省略できます。認識されない場合はAccessible IPTVでテレビを見ると話し、質問にチャンネル名で答えてください。ライブ一覧全体を検索します。Siriの更新には時間がかかります。アプリ名を省くには個人用ショートカットを作り、チャンネル選択をSky Mixに設定して、Sky Mixを再生、Sky Mixに切り替え、またはSky Mixを見ると名付けてください。

# SharePlay

FaceTime通話を開始するか参加し、再生を始めてから、プレーヤーで「SharePlayを開始」を選びます。全員がこのアプリをインストールし、自分のプレイリストとログイン情報を追加する必要があります。URLとパスワードがほかの参加者に送られることはありません。チャンネル変更、再生、一時停止は共有されます。再生位置の移動は、対応する配信元でのみ同期されます。配信元ごとの遅延により、ライブ映像がフレーム単位で一致しないことがあります。最小化やバックグラウンド再生中もSharePlayは続きます。再生を停止すると、このデバイスはセッションから退出します。「SharePlayから退出」は自分だけ退出し、「全員のSharePlayを終了」は全員のセッションを終了します。署名済みアプリとインストール用プロファイルには、SharePlayグループセッションの許可が必要です。
